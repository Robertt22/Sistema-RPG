# Sistema RPG em Java

Um projeto de RPG desenvolvido em Java com foco na aplicação dos conceitos de Programação Orientada a Objetos (POO), lógica de programação e desenvolvimento de sistemas.

##  Sobre o projeto

Este projeto pessoal tem como objetivo aprimorar minhas habilidades em Java através do desenvolvimento de um sistema de RPG, explorando conceitos como encapsulamento, organização de classes, atributos e lógica de combate.

A proposta é construir gradualmente um sistema que permita criar personagens, definir seus atributos e participar de combates.

---

###  Funcionalidades implementadas
- Criação de entidades
- Sistema de atributos
- Sistema de combate
- Multiplicadores de dano

###  Funcionalidades futuras
- Sistema de defesa
- Sistema de classes e especializações
- Sistema de Dungeons
- Sistema de loja
- Sistema de inventário

---

### 🛠️ Tecnologias utilizadas
- **Java** — Linguagem de programação
- **Git** — Controle de versão
- **IntelliJ IDEA** — Ambiente de desenvolvimento

---

###  Objetivo

Evoluir o projeto continuamente, aplicando boas práticas de programação e aprofundando conhecimentos em Java e Programação Orientada a Objetos.
